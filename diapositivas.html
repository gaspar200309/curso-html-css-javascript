Curso de React

Qué es React, cómo funciona la Web, IPs y Puertos

¿Qué es la Web?

  • La Web es un sistema de páginas y aplicaciones conectadas mediante Internet.
  • Los navegadores usan HTTP y HTTPS para acceder a sitios.
  • La información viaja entre clientes y servidores.
  • HTML, CSS y JavaScript son las tecnologías principales.

¿Cómo funciona Internet?

  • El usuario escribe una URL.
  • El DNS traduce el dominio a una IP.
  • El navegador envía una solicitud al servidor.
  • El servidor responde con archivos y datos.
  • El navegador renderiza el contenido visualmente.

¿Qué es una Dirección IP?

  • Una IP identifica dispositivos en una red.
  • Permite la comunicación entre computadoras.
  • Existen IPs públicas y privadas.
  • 192.168.1.1 es un ejemplo IPv4.

¿Qué es React?

  • React es una biblioteca de JavaScript creada por Meta.
  • Se usa para crear interfaces modernas.
  • Trabaja mediante componentes reutilizables.
  • Permite construir aplicaciones rápidas y dinámicas.

¿Para qué sirve React?

  • Crear aplicaciones web dinámicas.
  • Desarrollar dashboards y paneles administrativos.
  • Construir Single Page Applications.
  • Mejorar la experiencia del usuario.

¿Qué es JSX?

  • JSX mezcla JavaScript con HTML.
  • Permite crear interfaces visuales fácilmente.
  • Los componentes retornan JSX.

Componentes en React

  • Son piezas reutilizables de interfaz.
  • Dividen la aplicación en módulos.
  • Facilitan mantenimiento y escalabilidad.

Ventajas de React

  • Código reutilizable.
  • Virtual DOM para mejor rendimiento.
  • Escalable para proyectos grandes.
  • Gran comunidad y ecosistema.
